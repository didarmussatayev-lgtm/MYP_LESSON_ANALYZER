# Word-шаблон отчёта

Файл: `templates/lesson_report_template.docx`.

Сайт собирает Word-отчёт по этому шаблону **при каждом скачивании**. Отсюда
два следствия:
- в отчёте всегда актуальные комментарии из «Обсуждения»;
- после правки шаблона все отчёты, включая старые уроки, скачиваются уже
  в новом оформлении.

## Что в шаблоне

1. Заголовок и сведения об уроке: тема, учитель, дата, предмет, класс,
   предметная группа, язык урока, длительность записи, время формирования отчёта.
2. **Key figures** — четыре ключевых показателя и строка-пояснение.
3. **Block 1** — план и факт по 10 пунктам unit planner.
4. **Block 2** — время речи учителя и учеников.
5. **Block 3** — вопросы учителя (сводка по типам и список), заявленный
   подход и практика, уровни inquiry по эпизодам.
6. **Block 4** — критерии оценивания: strands, возможность для учеников,
   свидетельство, идея на следующий урок.
7. **Block 5** — сильные стороны, зоны роста, рекомендация.
8. **Block 6** — обсуждение (комментарии методиста и учителя).
9. Методология и ограничения. В нижнем колонтитуле — номер страницы.

Заголовки на английском (как в документах IB). Содержание — выводы модели и
цитаты — приходит на языке, выбранном для урока.

## Как поправить оформление

1. Откройте репозиторий на GitHub → папка `templates` →
   `lesson_report_template.docx` → **Download raw file**.
2. Откройте файл в Word и меняйте что нужно:
   - шрифты, размеры, цвета, отступы;
   - логотип и название школы в верхнем колонтитуле
     («Вставка → Верхний колонтитул»);
   - текст заголовков и пояснений — можно перевести на русский или казахский;
   - порядок блоков — переносите блок целиком, вместе со служебными строками.
3. Сохраните как **.docx** с тем же именем.
4. На GitHub: папка `templates` → **Add file → Upload files** → перетащите
   файл → **Commit changes**. Если сайт берёт код из `main`, Railway
   пересоберёт его сам.
5. Скачайте любой отчёт на сайте и проверьте результат.

## Правила, чтобы не сломать заполнение

В шаблоне есть теги — текст в фигурных скобках. Сайт подставляет вместо
них данные.

- `{{ teacher_name }}` — поле. Его можно перенести в другое место
  и оформить, но **оформлять целиком**: весь тег одним шрифтом и цветом.
  Если сделать половину тега жирной, Word разрежет его на части, и поле
  не заполнится.
- Строки таблиц `{%tr for ... %}` и `{%tr endfor %}` — **служебные**,
  в готовом отчёте их не видно. Не удаляйте их и не объединяйте с соседними
  ячейками. Строка между ними — образец, она повторится для каждой записи.
- Абзацы `{%p if ... %}`, `{%p for ... %}`, `{%p else %}`, `{%p endfor %}`,
  `{%p endif %}` — тоже служебные и пропадают в готовом отчёте. Удалять
  можно только парой: например, весь Block 6 от `{%p if comments %}` до
  `{%p endif %}`.
- Любой текст без фигурных скобок можно менять как угодно.

Если после правки отчёт не скачивается, сайт сообщит об ошибке шаблона.
Верните предыдущую версию файла: на GitHub откройте `History` у файла
и загрузите прошлую версию.

## Поля, которые можно использовать

| Тег | Что подставляется |
|---|---|
| `{{ lesson_title }}` | тема урока |
| `{{ teacher_name }}`, `{{ subject }}`, `{{ grade }}` | учитель, предмет, класс |
| `{{ lesson_date }}` | дата урока (ДД.ММ.ГГГГ) |
| `{{ subject_group }}` | предметная группа MYP |
| `{{ lesson_language }}` | язык урока |
| `{{ duration }}` | длительность записи |
| `{{ generated_at }}` | когда сформирован отчёт |
| `{{ kpi.teacher_pct }}`, `{{ kpi.student_speech_pct }}`, `{{ kpi.questions }}`, `{{ kpi.plan }}`, `{{ kpi.note }}` | ключевые показатели |
| `{{ talk_time.teacher_pct }}` и др. | показатели времени речи (см. Block 2) |
| `alignment_rows`: `row.field_label`, `row.planned`, `row.observed_evidence`, `row.alignment` | план и факт |
| `question_counts`: `c.label`, `c.count`, `c.pct` | сводка по типам вопросов |
| `questions`: `q.timestamp`, `q.quote`, `q.category_label`, `q.rationale` | вопросы учителя |
| `{{ intended_vs_enacted_summary }}` | заявленный подход и практика |
| `{{ inquiry_summary }}`, `inquiry_episodes`: `ep.start_timestamp`, `ep.end_timestamp`, `ep.level_label`, `ep.rationale`, `ep.evidence` | уровни inquiry |
| `criteria`: `c.title`, `c.rows` → `r.strand`, `r.opportunity`, `r.evidence`, `r.suggestion` | критерии и strands |
| `strengths`, `areas_for_development`, `{{ suggested_next_lesson_strategy }}` | выводы |
| `comments`: `c.header`, `c.body` | обсуждение |
| `{{ methodology_notes }}` | методология и ограничения |

## Собрать шаблон заново из кода

`templates/build_template.py` создаёт исходный шаблон. Запускать его нужно,
только если вы хотите начать с чистого листа — **ручные правки в Word при
этом пропадут**.

```bash
cd templates && python build_template.py
```
